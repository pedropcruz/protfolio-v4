::locale-content{lang="en"}
  ::project-section{heading="THE CHALLENGE"}
  "Oficina do Comportamento" started with 3 therapists and quickly grew to a larger team. They needed a professional digital presence to build trust with parents. The critical requirement: **Zero dependency**. The clinical team needed to publish blog posts, update team members, and manage services without ever touching a line of code or calling a developer.
  ::
::
::locale-content{lang="pt"}
  ::project-section{heading="O DESAFIO"}
  A "Oficina do Comportamento" começou com 3 terapeutas e cresceu rapidamente. Precisavam de uma presença digital profissional para criar confiança com os pais. O requisito crítico: **Zero dependência**. A equipa clínica precisava de publicar artigos, atualizar a equipa e gerir serviços sem nunca tocar numa linha de código ou ligar a um developer.
  ::
::

::locale-content{lang="en"}
  ::project-section{heading="THE SOLUTION"}
  I built a Static Site (SSG) using Nuxt to ensure instant load times and top-tier SEO ranking—crucial for local discovery. 
  
  For content management, I implemented Prismic with a "Slice Machine" approach. I created custom, reusable components that allow the therapists to build complex page layouts visually. Now, they autonomously manage a rich blog ("Oficina de Sugestões") and keep the site alive, focusing on what they do best: therapy.
  ::
::
::locale-content{lang="pt"}
  ::project-section{heading="A SOLUÇÃO"}
  Construí um Site Estático (SSG) usando Nuxt para garantir tempos de carregamento instantâneos e ranking SEO de topo—crucial para descoberta local.
  
  Para gestão de conteúdos, implementei o Prismic com uma abordagem "Slice Machine". Criei componentes personalizados e reutilizáveis que permitem às terapeutas construir layouts de página complexos visualmente. Agora, gerem autonomamente um blog rico ("Oficina de Sugestões") e mantêm o site vivo, focando-se no que fazem melhor: terapia.
